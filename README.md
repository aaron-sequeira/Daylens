# WorkSight Agent

A local-first desktop activity tracker built with Electron, React, and SQLite.

## Development

```bash
# Install dependencies (from repo root)
pnpm install

# Start the app in dev mode
pnpm dev

# Run tests
pnpm test
```

## Build

```bash
pnpm build
```
